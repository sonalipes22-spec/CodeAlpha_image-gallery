# 🖼️ Image Gallery Website

A beautiful, responsive, and interactive Image Gallery Website built using HTML, CSS, and JavaScript. This project displays images in an attractive layout with smooth hover effects and transitions for an enhanced user experience.

## ✨ Features

- 🖼️ Attractive image gallery layout
- 📱 Responsive design for mobile, tablet, and desktop
- 🎨 Beautiful background and modern UI
- 🖱️ Hover effects on images
- ⚡ Smooth transitions and animations
- 🔍 Easy image browsing
- 💻 Clean and user-friendly interface

## 🛠️ Technologies Used

- **HTML5** – To create the structure of the image gallery.
- **CSS3** – To style the gallery, add hover effects, animations, and responsive layouts.
- **JavaScript** – To add interactive functionality, if implemented.

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Add your images to the `images` folder.
4. Check the image paths in your HTML file.
5. Open `index.html` in your web browser.
6. Explore the gallery and enjoy the design!
